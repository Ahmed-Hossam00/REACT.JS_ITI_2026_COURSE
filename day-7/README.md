# 📝 Card بسيطة

## المطلوب

اعمل Card شبه كارت تعريف بسيط فيه البيانات دي

🟢 صورة
🟢 اسم الشخص
🟢 Job Title
🟢 Description قصيرة (سطرين أو تلاتة)
🟢 زرار مكتوب عليه **Contact Me**

---

## Requirements

### Structure

🟢 استخدم HTML Semantics بشكل صح
🟢 استخدم عنوان (`h1` أو `h2`) للاسم
🟢 استخدم `p` للـ Job Title والـ Description
🟢 استخدم `button` أو `a` للزرار

### Fonts & Typography

🟢 استخدم Google Font
🟢 غير حجم الخطوط بحيث يكون فيه فرق واضح بين العنوان وباقي الكلام
🟢 استخدم `font-weight`
🟢 استخدم `line-height`
🟢 استخدم `text-align`

### Background

🟢 اعمل Background للصفحة بلون مناسب
🟢 اعمل Background مختلف للكارت
🟢 استخدم `background-color`

### Box Model

🟢 استخدم `padding` جوه الكارت
🟢 استخدم `margin` بحيث الكارت يبقى في نص الصفحة

- اعمل `border`
  🟢 استخدم `border-radius`

### CSS Units

🟢 استخدم `px`
🟢 استخدم `%`
🟢 استخدم `rem` مرة واحدة على الأقل

---

## Bonus (اختياري)

🟢 اعمل Hover للزرار يغير اللون
🟢 اعمل Shadow للكارت باستخدام `box-shadow`
