# 🎯 Assignment HTML & CSS

## Build a **Personal Profile Page** using **HTML & CSS only**.

- [ ✅] Header

- [ ✅] About Section
- [ ✅] Skills Section
- [ ✅] Contact Button
- [ ✅] Footer

# ✅ CSS Selectors

Use all of the following selectors:

- [ ✅] Universal Selector (`*`)
- [ ✅] Element Selector
- [ ✅] Class Selector
- [ ✅] ID Selector
- [ ✅] Group Selector
- [ ✅] Descendant Selector
- [ ✅] Child Selector (`>`)

- [ ✅] Show which selector has higher priority.

- [ ✅] `vh`
- [ ✅] `vw`

# ✅ Naming Convention

Use meaningful class names.

### ✅ Good

```css
.profile-card
.profile-image
.profile-info
.contact-button
```

### ❌ Bad

```css
.box1
.div2
.test
.abc
```

---

# ✅ CSS Variables

### Global Variables

- [ ✅] Create variables inside `:root`
- [ ✅] Use them throughout your project

Example:

```css
:root {
  --primary-color: #3498db;
  --secondary-color: #2ecc71;
  --text-color: #333;
}
```

### Local Variables

- [ ✅] Create at least one local CSS variable inside a specific selector.

---

# ✅ !important

- [ ✅] Use `!important` **only once**.
- [ ✅] Add a comment explaining why you used it.

Example:

```css
/* Needed to override another rule */
color: red !important;
```
